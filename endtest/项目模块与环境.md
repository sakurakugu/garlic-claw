# 项目模块与环境

## 所需环境

| 依赖 | 版本要求 | 用途 |
|------|----------|------|
| Node.js | >= 22 | 所有 JS/TS 运行时 |
| npm | 内置 | 包管理器 |
| Python | >= 3.10 | 启停脚本、进程编排 |
| Docker | 任意 | 生产部署 |
| SQLite | 内嵌 (Prisma) | 开发数据库 |

## 模块列表

### 核心包 (packages/)

| 模块 | 技术栈 | 端口 | 说明 |
|------|--------|------|------|
| `@garlic-claw/server` | NestJS 11 + Prisma + AI SDK v6 | HTTP :23330 / WS :23331 | 后端核心，提供 API、插件 WebSocket、AI 对话、MCP、Skill、子代理、自动化 |
| `@garlic-claw/web` | Vue 3 + Vite + Pinia + Element Plus | :23333 (dev) | 前端界面，多模型聊天、消息管理、自动化任务 UI |
| `@garlic-claw/shared` | TypeScript 类型定义 | — | 共享类型与插件运行时契约（纯类型，无逻辑） |
| `@garlic-claw/plugin-sdk` | TypeScript + WebSocket | — | 插件 SDK，支持 authoring/host/client 三入口 |

### 配置模块 (config/)

| 目录 | 说明 |
|------|------|
| `config/ai/` | AI Provider 配置（OpenAI / Anthropic / Gemini） |
| `config/mcp/` | MCP 工具服务配置（如 Tavily Search） |
| `config/personas/` | 人设/角色定义（系统提示词） |
| `config/plugins/` | 本地插件（如 `plugin-pc` PC 控制插件） |
| `config/skills/` | 内置 Skill（如天气查询） |
| `config/subagent/` | 子代理定义（explore 探索 / general 通用） |

### 工具模块 (tools/)

| 文件 | 说明 |
|------|------|
| `一键启停脚本.py` | 统一启停入口（由 `start.bat` / `start.sh` 调用） |
| `scripts/process_runtime.py` | 跨平台进程管理 |
| `scripts/dev_runtime.py` | 开发模式编排 |
| `scripts/docker_runtime.py` | Docker 生产部署 |
| `build-project-plugins.mjs` | 构建所有插件 |
| `refactor/` | 架构重构工具集（7 个子命令：指标检查、导出守卫、禁止导入等） |

### 文档模块 (docs/)

| `docs/插件开发指南.md` | 插件开发者 |
| `docs/后端模型调用接口说明.md` | 模型接入 |
| `docs/扩展内核契约说明.md` | 系统维护者 |
| `docs/扩展内核维护说明.md` | 系统维护者 |
| `docs/软件架构文档.md` | 开发者 |

### AI 集成

- **AI SDK v6** (Vercel `ai`) — 统一调用层
- **OpenAI** (`@ai-sdk/openai`)
- **Anthropic** (`@ai-sdk/anthropic`)
- **Google Gemini** (`@ai-sdk/google`)

### 数据 / 存储

- **数据库**: SQLite (Prisma ORM)
- **用户认证**: JWT + Passport + bcrypt
- **消息流**: SSE 流式输出

### 插件 / 扩展

- **插件协议**: WebSocket (`ws`)，`@garlic-claw/plugin-sdk` 封装
- **MCP 协议**: `@modelcontextprotocol/sdk` v1，可挂载外部工具服务
- **Skill 系统**: 脚本化技能，本地执行
- **子代理系统**: 委派子任务（explore 使用 webfetch+skill，general 无限制）

### 代码解析

- **Tree-sitter**: bash / powershell 语法解析（用于 shell 命令分析）

### 工程化

| 工具 | 用途 |
|------|------|
| TypeScript 6 | 类型检查 |
| ESLint 10 + `@typescript-eslint` | JS/TS 代码检查 |
| Ruff + MyPy | Python 代码检查 |
| Jest | 后端测试 |
| Vitest + Playwright | 前端测试 / E2E |
| Python 启停脚本 | 进程编排 |
| Docker Compose | 生产部署 |
| Git Hooks | 提交前检查 + 提交信息规范化 |

## 测试覆盖缺口

> 基于 `endtest/test.md` 分析，测试时间 2026-06-13，共通过 **1600+ 用例**，零失败。

### 🔴 阻塞性问题（server 测试套件无法运行）

| 问题 | 影响套件数 | 原因 |
|------|-----------|------|
| `@garlic-claw/shared` 未构建 | ~10 | Jest 找不到 workspace 包导出 |
| `@garlic-claw/plugin-sdk` 未构建 | ~33 | Jest 找不到子路径导入 |
| `McpServerDto` 缺少 `'env-ref'` 枚举值 | 1 套件 2 断言 | `envEntries.source` 校验装饰器未包含该值 |

**解决方案**: `npm run build` 后再次运行 `npx jest`。
